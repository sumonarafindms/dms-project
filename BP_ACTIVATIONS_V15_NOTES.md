# BP Activation Access v15

- Manager can view activation details for all BP assignments.
- Supervisor can only view BP assignments under employees in that supervisor's team.
- RSO can only view BP assignments under that RSO.
- BP continues to see only the currently assigned BP retailer's own SIM sales.
- BP activation details are calculated only inside the effective BP assignment period so historical BP code changes do not mix data.
- Month and SIM serial filters are available.
- Total GA, 150, 300, GA target, daily GA, SIM number, activation date/time and selling price are shown.
- No database migration is required for this release.
