# BP Assignment v13

- Retailer codes can be dynamically selected as BP under an RSO.
- One active BP is maintained per RSO. Assigning a new BP closes the previous assignment and preserves history.
- Effective date and optional GA target are stored on the BP assignment.
- Existing BP login automatically moves to the new retailer code when an RSO BP is changed.
- Admin BP Management, RSO My BP, Accounts BP list, and live BP dashboard are connected.
- BP users are created only from currently active BP retailer assignments.
